Pedal Build — Perfboard

Rothwell Love Squeeze

Modified JFET compressor build with added attack, release, and threshold controls. Based on the Rothwell Love Squeeze schematic with fixes for sidechain sputtering and treble loss.

Overview

The Rothwell Love Squeeze is a JFET-based compressor. Q1 (2N5457) sits in the feedback loop of IC1A (TL072). At rest, the JFET presents ~300Ω and IC1A runs at unity to 10× gain depending on the COMP pot setting.

When signal hits the input, a peak-to-peak rectifier (D3, BAR43S Schottky) develops a negative bias voltage at Q1’s gate, increasing its resistance and reducing IC1A’s gain — that’s the compression. Attack time is inherently very fast, limited only by the rectifier (half a wavelength of the input fundamental). IC1B handles makeup gain and output buffering.

🛠
Build format
Perfboard from scratch — full layout freedom, no existing PCB to modify.

Known Design Issues

1. Sidechain High-Pass Filter → Threshold Sputtering

C4 in the sidechain path forms a high-pass filter around ~106Hz. At low frequencies:

  • Rectifier sees reduced drive and higher ripple on the envelope
  • Phase shift causes compression to snap in and out right at the threshold
  • Audible as a blatty, sputtering decay on chords — especially E/A strings
  • Only occurs at the threshold — louder or quieter signals are fine
  • Confirmed design flaw in LTSpice — not a layout or component selection issue
⚠️
Fix
Replace C4 1.5nF → 68nF and add 1MΩ in parallel with the resistor paired with C4 (effective ~500K). Corner drops from ~106Hz to ~4.7Hz — essentially full-range sidechain.
⚖️
Tradeoff
Full-range sidechain allows some pumping on big low-frequency transients. Because the JFET attack is so fast, this is far less noticeable than on traditional compressors. An untested alternative is a −6dB shelving filter below 100Hz in the sidechain.

2. Treble Loss (C12)

C12 in IC1A’s feedback rolls off high frequencies. Stock value ~15nF cuts above ~2.2kHz — source of the pedal’s “dark” reputation.

⚠️
Fix
Replace C12 15nF → 4.7nF. Raises treble corner to ~7.5kHz.

3. Release Ripple Artifacts

Stock R11 (10K) is too low, causing rectifier ripple to modulate Q1’s gate and creating intermodulation artifacts on the compression envelope.

⚠️
Fix
Replace R11 with 15K fixed + 25K pot — adjustable ~150–400ms release range.

Build Tips

  • Socket both IC1 (TL072) and Q1 (2N5457). JFET pinch-off voltage varies between units and directly affects threshold behaviour. Being able to swap is worth it.
  • Add 100nF ceramic decoupling caps from each IC supply pin to GND, placed physically close to the IC. C5/C6 handle bulk storage; these handle high-frequency noise.
  • Keep sidechain wiring short. The rectifier and envelope section is susceptible to noise pickup. Keep it away from the input path.
  • Wire pots off-board with short leads. Keep pot wiring away from the input section to avoid noise coupling.
  • VB mid-rail (set by R7 47K divider) is referenced by several components — make sure it has low impedance. C5/C6 handle this; don’t skip them.
  • Fixed resistors in series with pots are not optional. 4.7K for attack, 15K for release, 500K for threshold — they set the minimum value and prevent a floating gate or 0Ω short.
  • C1 and C2 values still need to be confirmed from the original schematic — not fully legible in the schematic photo.
